# Azure Storage Project

A .NET 8 project demonstrating Azure Storage services using an ASP.NET Core MVC Web App and Azure Functions.

## Projects

### AzureStorageWebApp

ASP.NET Core MVC application using:

* Azure Table Storage
* Azure Blob Storage
* Azure Queue Storage
* Azure File Storage

### AzureStorageFunctions

.NET 8 Azure Functions project demonstrating:

* Table Storage
* Blob Storage
* Queue Storage
* File Storage

## Requirements

* .NET 8
* Visual Studio 2022
* Azure Functions Core Tools
* Azure Storage Account

## Run

1. Configure the Azure Storage connection string.
2. Open the required `.csproj` file.
3. Run the application or Function App.
